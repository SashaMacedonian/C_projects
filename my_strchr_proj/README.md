**ТЗ: Реализация `strchr`**

Напиши `my_strchr(const char* str, int c)` которая:
-   Ищет **первое** вхождение символа `c` в строке `str`
-   Возвращает указатель на найденный символ
-   Если не найдено → возвращает `NULL`
-   **Важно:** должна находить и `'\0'`, если `c == '\0'`
-   Без проверок NULL внутри (как стандартная `strchr`)
-   Две реализации: индексная + указательная
